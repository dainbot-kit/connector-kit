# connector-kit

Files for connecting tools, apps, and agents on a Mac + GitHub.

- `connector-bot/RULES.md`: the Connector bot's scope and restriction rules.
- `research/mac-github-connection-methods.md`: every way to connect things on a Mac + GitHub (APIs, MCP, webhooks, macOS bridges, n8n/Shortcuts/Zapier, agent-to-agent, browser automation), with sources, costs, and risks. Researched 13 Nov 2026.
- `skills/agent-builder/SKILL.md`: a skill that interviews you one question at a time, then builds a working agent (shell, launchd, Shortcuts, or a Python watcher) with a one-line test.
- `shortcuts/dictation-to-skill.md`: build steps for the "Make Skill" Shortcut and voice/keyboard triggers.
- `examples/`: short runnable Python demos of common agent patterns (a tool loop, ReAct, a graph, sandboxed code execution, and a skill library). See `examples/README.md`.
- `flowchart/`: a decision-tree image for choosing an automation or agent pattern. See `flowchart/README.md`.
