This folder is a top-down decision tree, as a real image, for choosing an automation or agent pattern. It starts at "I want to automate something," uses the distinction that automation is a fixed path you draw and an agent is a model that chooses the path, then branches into seven options (deterministic automation, LLM-assisted automation, agentic workflow, autonomous agent, computer use, multi-agent, and a procedural-memory / skill library), with a note on what belongs in the context window and how the tool-calling cycle runs. To re-render from the Graphviz source, install Graphviz and from this folder run `dot -Tsvg -o automation-decision-tree.svg automation-decision-tree.dot` and `dot -Tpng -Gdpi=180 -o automation-decision-tree.png automation-decision-tree.dot`.
